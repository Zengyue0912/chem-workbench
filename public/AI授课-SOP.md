# 高中化学 AI 授课 SOP

在首页点「AI 授课 SOP」，或从左侧进入「AI 授课」。在「按考法学」里选册别、章节、考点和学习内容，点「开始学」。上方显示这节的总控路线，右边显示本步的输入、操作、输出、注意事项和完成标准。点「下载当前 SOP」可以保存所选内容的完整流程。

## 按考法学的总控路线

同一个考点也可以有不同路线。例如酸碱滴定里，求浓度先从读数求用量，判断误差先找变了哪个量，判断终点先确认题设的颜色与持续时间。

图文步骤由学生核对后继续，检查题选对才开放下一步。完成一步后，右侧会带出刚确认的结果。

| 编号 | 学习内容 | 技术路线 |
| --- | --- | --- |
| AIL-120 | 由滴定用量求浓度 | 从两次读数求用量 → 匹配标准液的浓度与体积 → 求标准液的物质的量 → 按中和比例换算待测物 → 用样品体积求原浓度 |
| AIL-121 | 判断滴定结果偏高或偏低 | 标出计算式中的变量 → 追踪尖嘴里多出的体积 → 核对样品量是否变化 → 沿计算式判断偏差 |
| AIL-122 | 识别滴定终点信号 | 找出题设的终点判据 → 筛掉短暂的局部变色 → 记录符合判据的读数 |
| AIL-123 | 写净离子方程式 | 先定反应条件与产物 → 决定哪些物质拆成离子 → 消去两侧相同的微粒 → 核对原子数和总电荷 |
| AIL-124 | 按环境判断离子共存 | 圈出溶液的限制词 → 补上隐含的环境离子 → 找出一对会反应的离子 → 复核剩余各组 |
| AIL-125 | 用电子守恒求用量或价态 | 标出变化元素的价态 → 由升降判断得失电子 → 把单个原子换成总量 → 令得失电子总量相等 |
| AIL-126 | 按溶质守恒算稀释量 | 找出稀释前后相同的量 → 选出稀释后的总体积 → 用浓度趋势检查算式 |
| AIL-127 | 判断容量瓶操作与配液误差 | 跟踪转移的溶质量 → 用定容确定最终体积 → 确认混匀后才能代表整体 → 用 n/V 判断配液误差 |
| AIL-128 | 判电极、电子流向和半反应 | 先确认电池在放电 → 在半反应中找氧化极 → 区分外导线里的载流微粒 → 由电荷平衡判盐桥迁移 → 验算半反应两侧电荷 |
| AIL-129 | 恒温比较 Q 与 K 判移动方向 | 核对方程式和温度 → 按物态写反应商 → 把当前组成代入 Q → 由大小关系判断方向 |
| AIL-130 | 由温度和热效应判断 K | 从 ΔH 读正逆反应的热效应 → 用升温判断 K 的变化 → 分清催化剂的作用 |
| AIL-131 | 由电子域判断构型与键角 | 在结构式里找到中心原子 → 把成键方向和孤对一起计数 → 先排电子域再标实际原子 → 按原子位置核对构型 |
| AIL-132 | 由构型与键偶极判断分子极性 | 把键画到实际构型上 → 核对方向与大小能否抵消 → 由合量判断整体极性 |
| AIL-133 | 按官能团判断酯化产物中的杂质去向 | 区分羧基和酯基 → 判断羧酸处理后的形式 → 按溶解性判断杂质去向 |
| AIL-134 | 拼合热化学方程式求焓变 | 把目标反应和物态写全 → 反向时同时改焓变符号 → 系数倍乘时同步改焓变 → 相加并核对被消去的物质 |
| AIL-135 | 先算滴定结果，再判断误差 | 把两种浓度的所求分开 → 建立两边共用的浓度式 → 给实际值配上入瓶体积 → 在同一个式子里比较两行 → 写清偏差从哪里来 |
| AIL-136 | 先判构型，再用构型判极性 | 分别清点两种分子的电子域 → 确认从构型接到偶极的顺序 → 从构型标出键偶极方向 → 用合量解释极性的差别 |

## AIL-100 · 视频微课总控

- **输入** 教材章节或知识点
- **输出** 微课要点、卡点反馈、换题和隔天复习记录
- **执行顺序** AIL-101 → AIL-102 → AIL-103 → AIL-104 → AIL-105 → AIL-106

每次显示一个主要任务。先看微课，再用一道题找卡点。实验或模型观察可选。根据首次作答选择复测题，答对后安排隔天复习。

### AIL-101 · 选知识点

- **输入** 教材章节或搜索词
- **操作** 在目录或搜索结果里选一个专题。
- **输出** 一个已上线的专题，带配套视频和题目。
- **注意事项** 搜索不到时可以换章节或缩短关键词。
- **完成标准** 页面显示所选专题的视频。

### AIL-102 · 看微课

- **输入** 专题及对应视频
- **操作** 播放视频，留意图示中的关键变化。视频播放结束后自动进入试题。
- **输出** 一条准备拿去做题的规则。
- **注意事项** 视频进度和学习效果分开记录。看完要用题检验。
- **完成标准** 视频播放结束，或学生主动确认看完并进入试题。

### AIL-103 · 试一题

- **输入** 视频中的规则与诊断题
- **操作** 先独立选一个答案。答错进入补讲，答对进入巩固。
- **输出** 首次答案和这道题暴露的卡点。
- **注意事项** 重选时保留首次答案。启用模型时可主动请求换一种讲法。
- **完成标准** 提交一次作答，页面显示对应反馈。

### AIL-104 · 做观察

- **输入** 当前专题配套的实验或模型
- **操作** 打开场景，按观察提示操作，再返回 AI 授课。
- **输出** 一次观察。滴定专题可带回本次新增测量。
- **注意事项** 这是可选步骤。虚拟实验结果用于课堂练习。
- **完成标准** 从对应场景返回。滴定可额外核对初读数、末读数、差值和终点状态。

### AIL-105 · 换题验证

- **输入** 诊断题的首次作答
- **操作** 首答错误时先练同一基础步骤，首答正确时做应用题。
- **输出** 独立复测的首次和最新作答。
- **注意事项** 这一步答错可重做，也可带着当前专题进入 AI 解题。
- **完成标准** 独立做完另一道题，答对后记录复测通过。

### AIL-106 · 隔天复习

- **输入** 复测通过时间和本专题复习题
- **操作** 复测通过满 24 小时后，回来做一道不同的题。
- **输出** 隔天复习的作答和反馈。
- **注意事项** 未到开放时间时，页面显示可复习的时间。
- **完成标准** 提交复习题并答对。

## 滴定样板

先看读数为什么相减，再用一组新读数试一题。可进手动滴定做一条测量，返回后对照读数差和终点。

视频是预先生成的。配置模型时可以主动请求另一种讲法。首次与最新作答保存在当前浏览器。
