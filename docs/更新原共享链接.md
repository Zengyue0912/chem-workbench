# 更新原共享链接

已有的正式站点是 `playful-salamander-f0038b`。2026 年 11 月 12 日的 AI 授课和 AI 解题已发布。下次改好后，仍向同一个项目做正式发布，老师和同学刷新原网址就能看到新版。[工作台原链接](https://playful-salamander-f0038b.netlify.app/)

1. 从最新版压缩包解压一份作为发布目录。在能看到 `netlify.toml` 和 `public` 的那一层打开终端。
2. 执行 `npm ci` 安装后台所需的依赖。首次使用 CLI 时，执行 `npx netlify-cli@27.16.2 login` 登录有该项目权限的账号。
3. 执行下面的命令，把网页和云课堂后台一起发布。

```powershell
npx netlify-cli@27.16.2 deploy --prod --no-build --site playful-salamander-f0038b --dir public --functions netlify/functions
```

4. 发布完成后，用无痕窗口打开原链接。首页能进入 AI 授课和 AI 解题，再打开健康检查确认 `mode` 是 `cloud`，`configured` 是 `true`。[云课堂健康检查](https://playful-salamander-f0038b.netlify.app/api/data/health)

教师密码、参加码和会话密钥由原 Netlify 项目的环境变量提供。云课堂数据保存在同一站点的存储里。重新发布网页后，教师仍从原站点进入后台。[教师后台](https://playful-salamander-f0038b.netlify.app/teacher.html)
